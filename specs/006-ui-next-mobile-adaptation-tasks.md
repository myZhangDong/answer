# 006 `ui-next` 移动端适配 Tasks

## 使用方式

这份清单只跟踪 `006` 规格下的 `ui-next` 移动端适配，不与内容门户主任务清单混写。

状态建议：

- `[ ]` 未开始
- `[~]` 进行中
- `[x]` 已完成

## 已确认默认前提

- [x] 第一阶段优先使用 Tailwind 原生响应式能力完成适配
- [x] 第一阶段不引入独立 `mobile.css` 或移动端页面副本
- [x] 第一阶段按“前台完整适配、后台基础可用”收口
- [x] 移动端主导航默认采用抽屉式或 `sheet` 形态
- [x] 首页和详情页侧栏内容在移动端默认下沉，不直接删除高价值模块
- [x] 搜索在移动端继续保留可触达入口
- [x] 允许代码块、表格、筛选 chips 等局部横向滚动，但不允许整页横向滚动
- [x] 第一阶段不处理旧 `ui/` 的移动端适配

## Phase A：公共壳层与全局响应式基线

目标：先收口 `Header / MainLayout / Footer` 和全局容器规则，避免后续每个页面单独补洞。

### Header

- [x] 为移动端新增主导航入口
- [x] 为移动端接入 `sheet` / 抽屉式导航容器
- [x] 在移动端保留首页、视频教程、开源项目三类入口
- [x] 在移动端保留搜索触达入口
- [x] 在移动端保留管理员入口或管理员菜单入口
- [x] 确认普通访客入口在小屏下不溢出、不依赖 hover

### MainLayout

- [x] 小屏下将公共壳层改为单列流式布局
- [x] 主内容容器在小屏下收缩边距与上下间距
- [x] 左侧导航隐藏后不再保留桌面型空白
- [x] 公共页的主内容与侧栏区域具备统一下沉顺序

### LeftSidebar

- [x] 明确桌面侧栏只在大屏展示
- [x] 小屏下由 Header 移动导航补位，不再让导航能力缺失
- [x] 确认导航高亮逻辑在桌面和移动端保持一致

### Footer

- [x] 去掉不适合窄屏的强制 `nowrap`
- [x] 收缩超宽 Logo、品牌语和版权区域在小屏下的占用
- [x] 链接区在移动端改为可换行或纵向排列
- [x] 联系方式与社交入口在移动端不溢出
- [x] Tooltip / 二维码浮层在触屏环境下保持基本可用或提供降级表现

### 全局样式基线

- [ ] 统一公共容器在 `360/390/430/768/1280` 视口下的断点表现
- [ ] 梳理需要全局复用的响应式间距、卡片内边距和 section 间距
- [ ] 确认全站默认无整页横向滚动

验收：

- [ ] 小屏下已具备完整顶层导航能力
- [ ] 公共壳层在移动端不再表现为桌面双栏缩放版
- [ ] Footer 在手机宽度下无明显溢出和遮挡
